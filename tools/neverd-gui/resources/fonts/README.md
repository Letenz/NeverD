# Bundled workbench fonts

Unmodified Noto fonts, licensed under the SIL Open Font License 1.1.
The adjacent `*-OFL.txt` notices are embedded alongside these fonts.
No runtime download or desktop font installation is needed.

Noto Sans covers Latin, Greek and Cyrillic. Arabic and CJK faces cover all
supported interface languages; Noto Sans Mono provides the default code face.
The CJK collection includes regional Chinese, Japanese and Korean faces.
