# الجدولة الاستباقية لتعريفات Windows

يتيح كائن `scheduling` الاختياري استباقًا حتميًا على CPU0 لتعريفات Windows x64 مع Unicorn أو KVM أو WHP. عند حذفه تبقى الجدولة التعاونية ويتقدم الوقت الافتراضي عند الخمول فقط. يجب أن يكون الحقلان عددين صحيحين موجبين وأن يتسع `uint64_t` لحاصل ضربهما. يختار الكائن الفارغ القيم الافتراضية أدناه.

```json
{
  "scheduling": {
    "quantum_instructions": 1024,
    "instruction_time_100ns": 1
  }
}
```

يحدد `quantum_instructions` عدد محاولات تعليمات الآلة المقبولة للخيط. ويخصص `instruction_time_100ns` وقتًا افتراضيًا لكل محاولة، ولا يقدّر سرعة العتاد. تكتمل واجهات النموذج ومعاملات التعليمات قبل التبديل. لا تعيد حدود الأحداث ضبط الشريحة المتبقية. يحفظ التقرير السياسة في `configuration.scheduling`.

تتيح `KeSetPriorityThread` و`KeQueryPriorityThread` أولوية التنفيذ عند `PASSIVE_LEVEL`. يقبل الضبط 1..31 ويعيد القيمة السابقة؛ الصفر محجوز. يبدأ كل خيط في الملف الحتمي بالأولوية 8. يُختار الخيط الجاهز الأعلى أولوية، وتتبادل الأولويات المتساوية التنفيذ حسب ترتيب الجاهزية والحصة. إيقاظ خيط أعلى أولوية أو تعديل الأولوية يستبق التعليمة الضيفة التالية تحت DISPATCH_LEVEL مع حفظ بقية الحصة. تشترك الاستدعاءات المتداخلة وSEH في أولوية الخيط المالك. يبقى كائن خيط النظام المنتهي قابلًا للاستعلام ما دام محتفظًا بمرجع وحتى تحريره، ولا يُدعم تعديل خيط ينتهي أو انتهى. تنتهي كائنات خيوط الاستدعاء المستعارة مع مالكها، فلا تنقل إعادة استخدام المكدس أولوية قديمة.

تتبع ملكية mutex في النواة الخيط المنطقي عبر الاستدعاءات المتداخلة وSEH. يحتفظ `KeWaitForSingleObject` بهذه الهوية للاكتساب المؤجل، ويمكن للمالك تنفيذ `KeReleaseMutex` من أي مكدس تابع له. يستمر تعطيل APC العادية حتى آخر تحرير متكرر، وترفض العودة الخارجية ترك mutex مملوكاً.

تستخدم الاستمرارات الجاهزة والمهام الجديدة وخيوط النظام ترتيب جاهزية مشتركًا. تشترك الاستدعاءات المتداخلة وSEH في شريحة الخيط. يحفظ التبديل سياق CPU كاملًا وهوية الخيط وحالة APC وIRQL الفعلي وتعيينات العملية. يسمح PASSIVE/APC بالاستباق؛ ويمنع DISPATCH وما فوقه تبديل الخيوط. تعطل المناطق الحرجة والمحمية APC دون منع استباق الخيط.

تدفع التعليمات المؤقتات وDMA وفق المواعيد الزمنية المتتابعة. ينتظر الإلغاء إتاحة قفل الإلغاء، وعودة dispatch في WDM. تنتظر إكمالات المزود القابلة للترحيل وسياسة الطاقة وخدمات PoFx حدًا عند PASSIVE؛ تبقى المواعيد الأصلية معلقة وتسجل الملاحظات وقت الخدمة الفعلي. تحافظ ردود النداء المستقلة الناتجة عن الساعة وردود PoFx الحاجبة على الخيط الأصلي على ملكية منفصلة. تُحسم نتائج الانتظار عند موعدها قبل إعادة ضبط مؤقت أو إشارة حدث لاحقة، حتى إذا عبرت محاولة تعليمة واحدة الموعدين.

لا ينفذ هذا الملف فئات أولوية Windows أو تعزيزها الديناميكي، أو وحدات CPU متوازية لنموذج النظام، أو تعشيق مقاطعات عشوائيًا، أو تسليم APC، أو إنشاء وجدولة خيوط Windows ring3. التنفيذ المتوازي للمعالج قدرة مستقلة. تختبر تعريفات أصلية مترجمة الشرائح القصيرة وحالة الفاصلة العائمة وGS والانتظار المحدد زمنيًا وإرفاق العمليات المتداخل والإلغاء واستمرارات PoFx. تظل أدلة تشغيل النظام الأصلية على ARM64 منفصلة.
