# Reproducible type-library dates

The Linux, Windows, Darwin, UEFI and FreeBSD type generators honor
`SOURCE_DATE_EPOCH` (non-negative integer Unix seconds) for the generated
notice's UTC date. Without it they retain the local current date. Pin the
same epoch, source headers and toolchain when comparing generated bytes;
this date control alone does not establish input provenance or ABI validity.
The date helper's focused checks run with
`python3 -m unittest scripts.tests.test_type_generation_date`.

A successful date-helper check is not a type-generation or ABI check. Full regeneration requires a built NeverD, clang, and the matching source headers/sysroots. Record the exact source revisions, compiler and NeverD versions, input hashes and output hashes with each generation; existing header notices do not provide a complete historical input receipt.
